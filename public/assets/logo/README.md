# Cognixs Logo Assets

Place your custom logo files here:
- `logo-mark.svg` or `logo-mark.png`: Hexagonal "C" with "X" mark
- `logo-full-light.svg` or `logo-full-light.png`: Full logo for light theme
- `logo-full-dark.svg` or `logo-full-dark.png`: Full logo for dark theme
- `favicon.svg` / `favicon.ico`: Studio browser icon

The website is configured to automatically pick up assets placed in this folder or fallback to the vector design system!
